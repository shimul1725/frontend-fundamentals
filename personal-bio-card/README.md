# Personal Bio Card 🪪

A simple, responsive personal bio card built with pure HTML and CSS — no frameworks, no JavaScript. This project focuses on semantic HTML structure and Flexbox layout fundamentals.

Part of the [Frontend Fundamentals](../) learning series.

## 🎯 What I Practiced

- **Semantic HTML5 tags** — `<header>`, `<section>`, `<article>`, `<footer>` used according to their intended meaning, not just `<div>` everywhere
- **Flexbox layout** — centering content, building a wrapping badge grid (`flex-wrap`)
- **CSS Custom Properties (variables)** — colors, spacing, radius, and shadows defined once in `:root` and reused throughout
- **Hover states & transitions** — smooth color/transform changes on interactive elements
- **`box-sizing: border-box`** — predictable sizing when combining width + padding

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, Custom Properties)

## 🚀 Running Locally

No build tools required — it's a static site.

```bash
git clone https://github.com/shimul1725/frontend-fundamentals.git
cd frontend-fundamentals/personal-bio-card
```

Then open `index.html` directly in your browser, or use the **Live Server** extension in VS Code for a better dev experience.
